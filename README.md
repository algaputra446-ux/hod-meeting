# H.O.D Meeting

Aplikasi web MVP untuk registrasi peserta, kuis, pembagian kamar, dan dashboard admin.

## Jalankan lokal

```bash
npm install
npm run dev
```

## Akun demo

- Admin: password `admin123`
- Peserta: `andi@example.com`, `budi@example.com`, atau `citra@example.com`
- OTP: `123456`

Data tersimpan di `localStorage` browser. Untuk penggunaan produksi, tambahkan database, autentikasi, dan OTP/email nyata.
